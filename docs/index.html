SERVICES

依頼できること

どんな制作や相談ができるのかを、作品とは別にまとめています。

01 / POSTER

ポスター・チラシ

園行事、地域イベント、施設案内、お知らせなど。情報を整理して、伝わる順番に組み立てます。

02 / SNS

SNS・サムネイル

LINE WORKS、SNS投稿、動画サムネイルなど、掲載先に合わせて見せ方を調整します。

03 / FIELD SUPPORT

保育・学育の現場制作

園だより、行事案内、掲示物、カード、教材、工作の見本や型紙など、現場で時間のかかる制作物を相談しながら整えます。

04 / DOCUMENT

資料・シート整理

ヒアリングシート、管理表、説明資料など、現場で迷わず使える形へ整理します。

05 / TOOL

小さな業務ツール

検索ページ、入力支援、管理画面など、日々の小さな面倒を減らす仕組みを作ります。

06 / CONSULT

相談から一緒に整理

何を作ればいいか決まっていない段階でも、目的や対象を聞きながら必要な形を考えます。
